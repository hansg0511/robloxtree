# Progression tuning (provisional)
Edit `src/ReplicatedStorage/Shared/ProgressionConfig.luau` for the current progression baseline. Each rarity row owns its stable ID, color, Forge unlock, optional minimum rarity milestone, level cap, power multiplier and outgoing ascension chance/cost. Do not rename existing saved IDs. Forge unlocks and floor milestones must be ordered. To change odds, edit RARITY_TAIL (elapsed Forge levels since a rarity unlocked, cumulative chance of rolling at least that rarity). Interpolate between points; actual rarity weights are adjacent tail differences and sum to one million, with one minimum integer weight reserved for each eligible tier to avoid accidentally retiring a rarity. A floor retires lower rarities. Maximum unlock and floor apply only to new crafts; ascension checks the destination unlock, not the floor. XP uses XP.Base/PerLevel; power = forged power × current rarity Power × (1 + (level − 1) × LEVEL_POWER_GROWTH). Successful ascension retains level. At cap XP is zero. Forge costs use FirstUpgrade, Scale, Exponent and Round; potency interpolates, log limits and ability pools are step milestones. Class offset remains a log-count adjustment, not an unconditional power buff. Existing mutations retain rolled parameters. `PremiumEconomyConfig.luau` owns recurring Gem rewards, crystal exchange price, crystal cost per rarity, Awakening/replacement prices, free family weights and potency fractions. `ForgeMutationRules.luau` owns within-family ability weights and species potency. `PITY_MAX` limits the default number of attempts; per-rarity Pity can override. Old Forge levels keep their numeric value. Slot 2 is granted free at Legendary+; slot 1 remains empty if the weapon was unmutated. Duplicate families are forbidden. StudioForgeSandbox refills Gems and crystals while enabled; disable its ENABLED flag to observe real deductions. No Robux purchases or leaderboard payouts are wired. Studio runtime validation pending. Existing smoke scripts updated; no new smoke suite.
